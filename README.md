# Childhood Memories — An Improv Session

A single-page slide deck for a Toastmasters variety session.

## The session

1. **Pick a paper** — your slip lists a partner number for every round.
2. **Find that number** — each round, find the person holding the number listed for it.
3. **Change every round** — new round, new number, new partner. Three rounds in all.

Each person shares for one minute. Every round gets a random topic, and the
goal is to share the childhood memory behind it.

**Improv tip:** use a story with *who, when, what, why*.

## Running it

No build step. Open `index.html`, or:

```
npx serve .
```

## Controls

- Click anywhere, press `→` / `Space` to advance; `←` to go back
- Topic wheel draws from a shuffled deck of 13 topics with no repeats
- Built-in one-minute speaking timer
